# FCL T800 Sim

Simulation et contrôle de mouvements de combat pour le robot humanoïde EngineAI T800, développés par FCL BOTS, la ligue française de combats de robots humanoïdes.

Site : https://fclbots.com
Premier gala : FCL 01, Paris, 2027

## Objectif
Entraîner en simulation des mouvements de combat (déplacements, garde, coups, esquives, chute et relevé), puis les transférer sur le robot réel, piloté en direct par un humain.

## Contenu
- sim/ : environnement de simulation du T800
- moves/ : bibliothèque de mouvements
- docs/ : notes techniques et résultats

## Statut
En cours de développement. Robot réel attendu début 2027.
